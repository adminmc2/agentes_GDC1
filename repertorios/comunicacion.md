# REPERTORIO DE EXPLOTACIÓN: Agente Comunicación
## Sistema de Agentes v5.0 — Nuevo Compañeros 1

---

## §1. PRINCIPIOS RESTRICTIVOS

Aplican a TODAS las opciones de explotación de la sección de Comunicación.

| Principio | Restricción |
|-----------|-------------|
| **CLT — Regla de oro** | Todo lo añadido reduce carga extrínseca o facilita carga germana. Si aumenta carga → eliminar |
| **10-15 min máximo** por actividad sin cambio de tipo | Cambiar tipo de actividad o agrupamiento después de 15 min |
| **Worked example obligatorio en A1** | Profesor modela con voluntario ANTES de pedir producción |
| **Significado antes que forma** | Comprensión global ANTES de análisis de funciones |
| **Input processing (VanPatten)** | Cada elemento nuevo embebido en 95-98% contexto conocido |
| **Feedback inmediato y específico** | "Mira cómo se dice en el diálogo" — nunca "está mal" |
| **Weaning off obligatorio** | Toda fase productiva: con modelo → parcial → sin modelo |
| **Regla 70/30** | 70% contenido nuevo + 30% reciclaje de vocabulario y gramática anterior |
| **Pre-Durante-Post obligatorio** | Para todo vídeo y audio. Enriquecer cada fase con técnicas del banco (`referencias/tecnicas-video-clase.md`): seleccionar 1-2 técnicas por fase |
| **Vídeo: fragmentar si >1 min** | CLT §5.5 información transitoria |
| **Banco de técnicas de vídeo** | 89 técnicas + 31 variantes disponibles en `referencias/tecnicas-video-clase.md`. Seleccionar según fase (Pre/Durante/Post), destreza, formato de agrupamiento y variables contextuales |

## §2. PROTOCOLOS

### §2.1 Protocolo A — Ciclo comunicativo (C1-C5)

Para actividades de comunicación auténtica y funciones comunicativas:

```
C1 CONTEXTUALIZACIÓN (2-3 min)
  Activar situación comunicativa + conectar con experiencia
  Usar SOLO vocabulario ya conocido

C2 COMPRENSIÓN DEL MODELO (5-8 min)
  Input comprensible: vídeo / audio / diálogo modelo
  Pre-Durante-Post obligatorio
  Verificar comprensión ANTES de pedir producción

C3 PRÁCTICA GUIADA (5-7 min)
  Reproducir modelo con apoyo + adaptar con datos reales
  Weaning off: con modelo → parcial → sin modelo
  Worked example: profesor modela primero

C4 PRODUCCIÓN AUTÓNOMA (5-8 min)
  Crear diálogo propio / interacción libre / tarea final

C5 CONSOLIDACIÓN (distribuida)
  24h: tarea | 1 semana: activación | 4 semanas: integradora
```

### §2.2 Protocolo C — Protocolo fonético (P1-P5)

Para actividades de pronunciación y ortografía:

```
P1 ESCUCHAR MODELO (1-2 min)
  Input auditivo saturado: 3-4 repeticiones

P2 DISCRIMINAR (2-3 min)
  ¿Suena igual o diferente? ¿Dónde está el sonido?

P3 REPETIR CON APOYO (2-3 min)
  Coral → individual, velocidad creciente

P4 PRODUCIR EN CONTEXTO (2-3 min)
  En palabras y frases nuevas

P5 ORTOGRAFÍA ASOCIADA (2-3 min)
  Regla sonido → letra + weaning off
```

### §2.3 Regla de derivación

| Si la actividad es... | Aplica... |
|---|---|
| Diálogo, interacción, role-play, producción oral, función comunicativa | Protocolo A (C1-C5) |
| Pronunciación / Ortografía | Protocolo C (P1-P5) |

## §3. OPCIONES DE EXPLOTACIÓN POR TIPO DE ACTIVIDAD

### §3.1 VÍDEO + DIÁLOGO MODELO

**Contexto:** Actividad con vídeo que presenta un diálogo modelo en situación comunicativa real. Elemento estructural de la sección: siempre hay un vídeo. Los alumnos ven el vídeo y completan huecos, responden preguntas o identifican funciones comunicativas.

**Banco de técnicas:** Consultar `referencias/tecnicas-video-clase.md` para enriquecer cada fase. Seleccionar 1-2 técnicas por fase según variables contextuales.

**Opción A — Pre-Durante-Post con vídeo como input principal**
- Cuándo: Primera exposición al diálogo, vídeo disponible, necesidad de comprensión global antes de detalle.
- Secuencia:
  - **Pre-visionado** (1-2 min): contextualizar + activar vocabulario + predicción. Técnicas del banco: fotograma misterioso (T1), lluvia de palabras visual (T3), emparejamiento imagen-palabra (T11), encuesta previa (T10).
  - **1.º visionado** sin pausas: pregunta guía ("¿Cuántos personajes? ¿De qué hablan?"). Técnicas: visionado sin sonido (T13), carrera de datos (T17), semáforo de comprensión (T29).
  - **2.º visionado** con tarea detallada: completar huecos / anotar datos. Técnicas: subtítulos con huecos (T25), tabla de observación guiada (T19), ¿quién dice qué? (T23), caza del error (T21).
  - **Post-visionado**: comprensión + extracción de funciones comunicativas. Técnicas: entrevista al personaje (T32), resumen en cadena (T40), cadena de preguntas (T70).
- Teoría: CLT §5.5 información transitoria + Pre-Durante-Post + Merrill: Activación.

**Opción B — Vídeo + análisis de funciones comunicativas + producción libre**
- Cuándo: Diálogo con múltiples funciones comunicativas, alumnos con base suficiente, objetivo de producción libre.
- Secuencia:
  - **Pre-visionado**: nube de vocabulario (T4) o mapa mental temático (T8) centrado en las funciones.
  - **1.º visionado** global → **2.º visionado** con pausa por función ("¿Cómo pregunta por los hermanos? ¿Cómo responde?"). Técnica: pausa y predicción (T15), congelación de imagen (T18).
  - **Post-visionado**: Listar funciones en pizarra → Producción libre. Técnicas: recreación de escena (T45), role-play con variación (T81), doblaje creativo (T30).
- Teoría: Merrill: Demostración + Aplicación + Integración. Focus on form (Long 1991).

**Opción C — Vídeo + role-play con variación**
- Cuándo: Diálogo con estructura reproducible, clase dinámica, objetivo de producción oral con adaptación personal.
- Secuencia:
  - **Pre-visionado**: fotograma misterioso (T1) o el tráiler personal (T12).
  - **1.º visionado** global → **2.º visionado** con texto visible.
  - **Post-visionado**: Reproducir diálogo exacto en parejas → Adaptar con datos personales → Representar. Técnicas: shadowing (T43), karaoke de diálogos (T51), role-play con variación (T81).
- Teoría: Weaning off (reproducir → adaptar → producir) + Merrill: Integración.
- Variantes aplicables: V98 (subtítulos progresivos), V99 (velocidad), V93 (punto de vista).

### §3.2 COMPRENSIÓN DEL DIÁLOGO

**Contexto:** Actividades de comprensión sobre el diálogo modelo: V/F, completar con nombres, relacionar información. Verifican que el alumno comprendió antes de producir.

**Opción A — Escalonada (global → detalle)**
- Cuándo: Después del 2.º visionado, múltiples actividades de comprensión, necesidad de verificar comprensión progresiva.
- Secuencia: Primero actividad global (completar nombres/personajes) → Luego actividad de detalle (V/F, correcto/incorrecto) → Corrección en parejas → Puesta en común selectiva (solo ítems con desacuerdo).
- Teoría: CLT: de lo simple a lo complejo + Gagné: verificar comprensión.

**Opción B — Búsqueda competitiva**
- Cuándo: Preguntas factuales claras, clase con baja energía, necesidad de activación.
- Secuencia: En parejas: encontrar respuestas lo más rápido posible → Primera pareja correcta levanta la mano, debe señalar DÓNDE en el diálogo está la evidencia → Punto extra de insignia para la pareja ganadora.
- Teoría: Gamificación integrada + metacognición (localizar evidencia).

### §3.3 PRODUCCIÓN ORAL SEMI-LIBRE

**Contexto:** Tarea final donde el alumno crea su propio diálogo usando las funciones comunicativas trabajadas. Incluye preparación, práctica y representación.

**Opción A — Con tarjetas de estrategia (Comodín, Tiempo Extra)**
- Cuándo: Alumnos con ansiedad, primera producción semi-libre de la unidad, necesidad de andamiaje emocional.
- Secuencia: Repartir tarjetas de estrategia (Comodín: el alumno puede pedir una palabra al profesor; Tiempo Extra: puede pedir 30 seg de preparación) → Preparar diálogo escrito en parejas (3 min) → Practicar oralmente (2 min) → Representar ante la clase (solo voluntarios) → Feedback: recast de errores comunicativos.
- Teoría: Reducción de ansiedad + scaffolding emocional + weaning off (escrito → oral).

**Opción B — Con gap de información asimétrica**
- Cuándo: Función comunicativa que permite intercambio real (uno tiene datos que el otro no), alumnos activos.
- Secuencia: Alumno A tiene ficha con datos de una familia ficticia; alumno B tiene ficha con datos de otra → Intercambian información oralmente usando funciones comunicativas → Verifican comparando fichas → Producen resumen oral ante la clase.
- Teoría: Merrill: Aplicación + interacción auténtica con propósito real.

**Opción C — Con escalado (individual → parejas → grupo)**
- Cuándo: Necesidad de preparación individual antes de interacción, alumnos que necesitan tiempo de procesamiento.
- Secuencia: Individual: preparar frases en cuaderno (2 min) → En parejas: practicar diálogo (3 min) → Ante la clase: representar (2-3 parejas voluntarias) → Feedback grupal.
- Teoría: Weaning off progresivo (escrito → oral parejas → oral público).

### §3.4 FUNCIÓN COMUNICATIVA: EXPRESIONES NUEVAS

**Contexto:** Actividades donde se presentan expresiones nuevas ligadas a una función comunicativa (ej: decir la hora). El alumno escucha, repite y aprende las fórmulas. NO es vocabulario suelto — son expresiones funcionales.

**Opción A — Ciclo comunicativo con modelo situacional**
- Cuándo: Función comunicativa nueva (primera aparición), expresiones con sistema propio (la hora tiene su lógica interna), necesidad de comprensión antes de producción.
- Secuencia: C1: contextualizar ("¿A qué hora coméis? ¿A qué hora es el recreo?") → C2: presentar el sistema completo (reloj/esquema visual) + audio del libro → C3: práctica guiada (profesor dice hora digital, alumnos dicen en palabras) con weaning off (con esquema → sin esquema) → C4: práctica en parejas con material real (cartelera, horarios).
- Teoría: Merrill: Problema + Demostración + Aplicación + Integración.

**Opción B — Con Sentence Builder para fórmulas**
- Cuándo: Expresiones con estructura combinatoria (Son las + número + y/menos + fracción), necesidad de sistematizar.
- Secuencia: Mostrar Sentence Builder (tabla con columnas sustituibles: Es/Son + la/las + número + y/menos + fracción) → Modelar 3-4 frases → Audio del libro → Producir con Builder visible → Producir sin Builder.
- Teoría: Sentence Builders (Conti) + weaning off.

**Opción C — Con categorización por situación**
- Cuándo: Múltiples expresiones que pueden agruparse por contexto de uso, necesidad de organización.
- Secuencia: Agrupar expresiones por categoría (ej: hora exacta / hora aproximada / preguntar la hora) → Audio del libro → Clasificar → Producir por categoría → Integrar todas.
- Teoría: CLT: segmentación + Gagné: organización previa.

### §3.5 PRÁCTICA ESCRITA DE FUNCIÓN COMUNICATIVA

**Contexto:** Actividades donde el alumno practica por escrito las expresiones de la función comunicativa (ej: escribir la hora, completar frases con fórmulas).

**Opción A — Weaning off progresivo**
- Cuándo: Función recién presentada, necesidad de consolidar reconocimiento antes de producción libre.
- Secuencia: Con esquema/modelo visible: completar → Sin esquema pero con inicial visible → Sin apoyo (de memoria) → Verificar en parejas → Comprobar con audio.
- Teoría: Weaning off 4 niveles + retrieval practice.

**Opción B — Práctica escrita → producción oral**
- Cuándo: La escritura prepara la producción oral siguiente, alumnos que necesitan apoyo escrito antes de hablar.
- Secuencia: Escribir respuestas individualmente → Verificar con audio → Producir oralmente las mismas respuestas → En parejas: pregunta-respuesta oral sin texto escrito.
- Teoría: Escrito como scaffolding para oral + weaning off (escrito → oral).

### §3.6 PRÁCTICA ORAL EN PAREJAS

**Contexto:** Actividades de interacción oral en parejas usando material concreto (cartelera de cine, horarios, fotos). El foco es la práctica de la función comunicativa en contexto.

**Opción A — Diálogo guiado → adaptación → producción libre**
- Cuándo: Libro proporciona modelo de diálogo, estructura pregunta-respuesta clara, primera práctica oral con la función.
- Secuencia: Modelo (1 min): profesor lee con voluntario → Repetir (2 min): en parejas el diálogo exacto → Adaptar (2 min): misma estructura, otros elementos del material → Weaning off (1 min): sin libro, de memoria → Opcional: "¿Qué pareja dice más frases correctas en 30 segundos?"
- Teoría: Weaning off + obligatorio → guiado → libre + gamificación integrada.

**Opción B — Information gap**
- Cuándo: Material que permite información asimétrica (alumno A ve parte de la cartelera, B ve otra parte), función que requiere intercambio real.
- Secuencia: Preparar gap: A tiene horarios de salas 1-3, B tiene horarios de salas 4-5 → Intercambiar oralmente → Verificar: comparar información completa → Producir resumen.
- Teoría: Merrill: Activación + Aplicación. Interacción comunicativa con propósito real.

**Opción C — Encuesta + puesta en común**
- Cuándo: Función que permite conexión personal (¿A qué hora cenas? ¿A qué hora te acuestas?), necesidad de movimiento.
- Secuencia: Dar 3-4 preguntas modelo con la función comunicativa → Circular por clase: cada alumno pregunta a 3-4 compañeros, apunta respuestas → Puesta en común: "¿Quién cena más tarde? ¿Quién se acuesta más temprano?" → Escribir 2-3 frases resumen.
- Teoría: Merrill: Integración + movimiento (ritmo atencional).

### §3.7 PRONUNCIACIÓN

**Contexto:** Actividades de pronunciación donde el alumno escucha un sonido y lo repite. Incluye discriminación auditiva y producción articulatoria. Siempre presente en la sección de Comunicación.

**Opción A — Discriminación auditiva → repetición → producción en contexto**
- Cuándo: Sonido nuevo (primera aparición), necesidad de discriminar antes de producir, palabras modelo disponibles.
- Secuencia: P1: profesor dice 4-5 palabras enfatizando el sonido → P2: "¿En qué se parecen todas estas palabras?" + discriminar pares (iguales o diferentes) → P3: repetición coral → individual → velocidad creciente → P4: producir el sonido en frases completas del diálogo → Audio del libro para verificar.
- Teoría: Protocolo fonético P1-P5 + CLT: de receptivo a productivo.

**Opción B — Con pares mínimos + texto + regla ortográfica**
- Cuándo: Sonido con regla ortográfica asociada (ej: /θ/ → z/c), necesidad de conectar sonido con escritura.
- Secuencia: P1: pares mínimos auditivos (caza/casa, cero/cero) → P2: discriminar y clasificar (¿suena /θ/ o no?) → P3: repetir → P4: producir → P5: presentar regla ortográfica (/θ/ + a,o,u → Z; /θ/ + e,i → C) → Completar huecos con regla visible → Sin regla.
- Teoría: Protocolo fonético P1-P5 + conexión fonema-grafema + weaning off.

### §3.8 ORTOGRAFÍA ASOCIADA

**Contexto:** Actividades específicas de ortografía donde el alumno aplica la regla sonido → letra. Completar huecos con la letra correcta, verificar con audio.

**Opción A — Completar con regla visible → sin regla**
- Cuándo: Regla ortográfica recién presentada, necesidad de consolidar la conexión sonido-letra.
- Secuencia: Con regla visible en pizarra: completar palabras → Sin regla pero con ejemplo modelo → Sin apoyo → Verificar con audio del libro → Corrección en parejas.
- Teoría: Weaning off + retrieval practice.

**Opción B — Dictado fonético progresivo**
- Cuándo: Alumnos que necesitan práctica adicional de escucha-escritura, clase que responde bien a retos.
- Secuencia: Profesor dicta 5 palabras: alumno escribe → Verificar con audio → Profesor dicta 3 palabras nuevas (no del libro) → Verificar con regla → Reto: "¿Quién escribe correctamente las 8?"
- Teoría: Retrieval practice + ampliación + gamificación integrada.
