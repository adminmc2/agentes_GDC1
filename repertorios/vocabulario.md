# REPERTORIO DE EXPLOTACIÓN: Agente Vocabulario
## Sistema de Agentes v5.0 — Nuevo Compañeros 1

---

## 1. PRINCIPIOS RESTRICTIVOS (aplican a TODAS las opciones)

| Principio | Restricción |
|-----------|-------------|
| **CLT — Regla de oro** | Todo lo que se añada debe reducir carga extrínseca o facilitar carga germana. Si aumenta carga → eliminar |
| **Máximo 5 ítems nuevos** por segmento | Si hay más → segmentar (categoría general → subcategoría → práctica → integración) |
| **10-15 min máximo** por actividad sin cambio de tipo | Cambiar de tipo o agrupamiento pasados 15 min |
| **Worked example obligatorio en A1** | Mostrar ejemplo resuelto ANTES de pedir producción |
| **Significado antes que forma** | Comprensión global ANTES de análisis lingüístico del vocabulario |
| **Input processing (VanPatten)** | Cada elemento nuevo embebido en 95-98% contexto conocido |
| **Feedback inmediato y específico** | "Mira la terminación" — nunca "está mal" |
| **Weaning off obligatorio** | En toda fase productiva: apoyo total → parcial → sin apoyo |
| **Regla 70/30** | 70% contenido de la sección + 30% reciclaje de contenido anterior |
| **No redundancia** | No presentar vocabulario simultáneamente en dos formatos (audio + texto a la vez = redundancia en nivel alto; en A1.1 texto como apoyo a audio SÍ se permite) |
| **Integración espacial** | Información visual integrada (etiquetas sobre la imagen, no separadas) |

## 2. OPCIONES DE EXPLOTACIÓN POR TIPO DE ACTIVIDAD

### §2.1 Escucha y repite (vocabulario)

**Contexto:** Actividades donde el alumno escucha términos nuevos de vocabulario y los repite. Suelen ir acompañadas de imagen (árbol genealógico, ilustración, foto).

#### Opción A — Ciclo 5 fases con input visual saturado

**Cuándo:** Vocabulario nuevo con imagen rica (árbol genealógico, lámina con etiquetas), patrón regular de género (-o/-a) o categorización clara, primera aparición del campo semántico.

**Secuencia:**
1. **F1a Modelling (2-3 min):** El profesor señala cada elemento de la imagen y nombra, repitiendo con variación natural (3-4 repeticiones por ítem). Integrar vocabulario previo en las frases modelo.
2. **F1b Awareness (2-3 min):** Pares mínimos en pizarra (masculino/femenino lado a lado). Preguntas cerradas: "¿Qué cambia?", "¿Dónde?", "¿Hay patrón?" NO dar la regla.
3. **Audio del libro:** Escucha 1 (global) + Escucha 2 (repetición por ítems).
4. **F2a Receptivo (2 min):** En parejas, uno dice nombre y otro dice relación/categoría (solo reconocimiento).
5. **F2b Productivo con weaning off:** Libro abierto → libro cerrado → de memoria.

**Principio teórico:** Input processing (VanPatten) + CLT integración espacial + Awareness questions (Conti 2023).

#### Opción B — Categorización semántica

**Cuándo:** Vocabulario con subcategorías claras (ej: parientes cercanos vs. lejanos, alimentos por tipo), campo semántico amplio (>10 ítems), necesidad de segmentar.

**Secuencia:**
1. **Categorías en pizarra:** Dibujar 2-3 categorías visuales (círculos, columnas).
2. **Audio del libro:** Escuchar los términos.
3. **Clasificar:** Los alumnos colocan cada término en su categoría (recortes, post-its, o señalando).
4. **Verificar:** Puesta en común. Preguntar "¿Por qué este va aquí?"
5. **Producir:** Frases usando términos de cada categoría.

**Principio teórico:** CLT segmentación (§5.6) — categoría general → subcategoría → práctica → integración.

#### Opción C — Sentence Builder

**Cuándo:** Vocabulario que se combina en patrones productivos (ej: "Mi [parentesco] se llama [nombre] y tiene [número] años"), vocabulario con estructura repetitiva.

**Secuencia:**
1. **Mostrar Sentence Builder:** Tabla/matriz donde se combinan bloques (columna 1: posesivo, columna 2: parentesco, columna 3: verbo, columna 4: complemento).
2. **Modelar:** El profesor genera 3-4 frases combinando bloques.
3. **Audio del libro:** Escuchar los términos dentro de frases.
4. **Producir con Builder:** Los alumnos generan frases combinando bloques.
5. **Retirar Builder (weaning off):** Producir sin la tabla visible.

**Principio teórico:** Sentence Builders (§8.13) + weaning off (§8.11).

### §2.2 Escucha y relaciona

**Contexto:** Actividades donde el alumno escucha un audio y relaciona/empareja información (nombres con personas, palabras con imágenes, etc.).

#### Opción A — Pre-Durante-Post auditivo con tarea de matching

**Cuándo:** Audio con múltiples elementos a emparejar, vocabulario parcialmente conocido, tarea de reconocimiento.

**Secuencia:**
1. **Pre-escucha (1 min):** Anticipar contenido. "¿Qué vamos a escuchar?" Activar vocabulario ya presentado.
2. **Durante — Escucha 1 (global):** "¿Cuántos nombres/elementos habéis pillado?" Sin escribir.
3. **Durante — Escucha 2 (detalle):** Realizar la tarea de matching (escribir nombre junto a imagen, unir con flechas, etc.).
4. **Post-escucha (2 min):** Corrección en parejas → puesta en común. El profesor confirma repitiendo la relación: "El abuelo de David se llama… ¡Carlos!"

**Principio teórico:** CLT información transitoria (§5.5) — segmentar escucha con tareas intermedias.

#### Opción B — Escucha segmentada

**Cuándo:** Audio largo (>1 min) o con muchos elementos, vocabulario mayoritariamente nuevo, alumnos con dificultades auditivas.

**Secuencia:**
1. **Fragmentar audio:** Escuchar solo los primeros 3-4 elementos. Emparejar.
2. **Verificar:** Corrección rápida del primer fragmento.
3. **Siguiente fragmento:** Escuchar los siguientes 3-4 elementos. Emparejar.
4. **Escucha completa final:** Todo el audio de seguido, como consolidación.

**Principio teórico:** CLT segmentación (§5.6) + información transitoria (§5.5) — audio <1 min por segmento con tarea concreta.

### §2.3 Escucha y traduce

**Contexto:** Actividades donde el alumno escucha frases y traduce palabras/expresiones a su L1.

#### Opción A — Deducción por contexto antes de traducción

**Cuándo:** Vocabulario parcialmente deducible por contexto, cognados presentes, relación con vocabulario ya conocido.

**Secuencia:**
1. **Escucha global (1 min):** Escuchar todas las frases sin hacer nada. "¿De qué hablan?"
2. **Identificar (1 min):** Segunda escucha. Subrayar las palabras a traducir.
3. **Deducir en parejas (2 min):** "Antes de traducir, intentad adivinar." Usar contexto de la frase + conocimiento previo.
4. **Traducir individualmente (1 min).**
5. **Puesta en común por L1s (1-2 min):** Detectar cognados y diferencias. "¿Los italianos? ¿Los franceses?"

**Principio teórico:** Significado antes que forma + deducción por contexto (curso-general).

#### Opción B — Traducción directa + reflexión contrastiva

**Cuándo:** Vocabulario sin cognados claros, conceptos culturalmente específicos (ej: "mujer" = wife y woman), necesidad de contraste L1-L2.

**Secuencia:**
1. **Escuchar y traducir directamente:** Sin fase de deducción — la traducción es el objetivo.
2. **Comparar traducciones por L1 (2 min):** "¿Cómo se dice en italiano? ¿Y en francés?" Construir tabla multilingüe en pizarra.
3. **Identificar falsos amigos o diferencias (1 min):** Señalar brevemente.
4. **Verificar comprensión:** Profesor dice la palabra en español, alumnos levantan tarjeta con traducción.

**Principio teórico:** Reflexión contrastiva L1-L2 + mediación lingüística.

### §2.4 Práctica oral en parejas (vocabulario)

**Contexto:** Actividades donde los alumnos practican oralmente en parejas usando el vocabulario de la sección.

#### Opción A — Diálogo modelo → adaptación → producción libre

**Cuándo:** El libro proporciona un modelo de diálogo, vocabulario con estructura pregunta-respuesta clara.

**Secuencia:**
1. **Modelar (1 min):** El profesor lee el diálogo modelo con un alumno voluntario.
2. **Repetir (2 min):** En parejas, repiten el modelo exacto.
3. **Adaptar (2 min):** Misma estructura pero con otros elementos (otros miembros, otros nombres).
4. **Weaning off (1 min):** Sin mirar el libro. De memoria.
5. **Gamificación opcional:** "¿Qué pareja puede nombrar más [elementos] sin mirar? ¡30 segundos!"

**Principio teórico:** Weaning off (§8.11) + producción obligatoria → guiada → libre (§8 F2b).

#### Opción B — Gap de información

**Cuándo:** Vocabulario que se presta a intercambio de información asimétrica (alumno A tiene datos que B no tiene), actividades de descripción.

**Secuencia:**
1. **Preparar gap:** Alumno A tiene imagen/información X, Alumno B tiene Y.
2. **Intercambiar oralmente:** Usando el vocabulario de la sección.
3. **Verificar:** Comparar ambas informaciones completas.
4. **Producir resumen:** Cada pareja resume oralmente lo descubierto.

**Principio teórico:** Merrill: activación + aplicación. Interacción con propósito comunicativo real.

#### Opción C — Encuesta + puesta en común

**Cuándo:** Vocabulario que permite conexión personal (familia, gustos, rutinas), necesidad de movimiento en clase.

**Secuencia:**
1. **Dar preguntas modelo:** 3-4 preguntas con el vocabulario de la sección.
2. **Circular por la clase:** Cada alumno pregunta a 3-4 compañeros y anota respuestas.
3. **Puesta en común:** "¿Quién tiene más hermanos en la clase?" (datos reales del grupo).
4. **Escribir resumen:** 2-3 frases sobre los resultados.

**Principio teórico:** Merrill: integración (conectar con el mundo del alumno) + movimiento (ritmicidad atencional).

### §2.5 Lee y escribe (vocabulario)

**Contexto:** Actividades con texto modelo que el alumno lee y usa como base para producir un texto propio.

#### Opción A — Lectura modelo → análisis de estructura → producción paralela

**Cuándo:** Texto modelo breve y claro, estructura replicable (presentar familia, describir persona), primera producción escrita del campo semántico.

**Secuencia:**
1. **Lectura global (2 min):** Leer el texto. "¿De qué habla?"
2. **Análisis de estructura (2 min):** Escribir en pizarra el esquema del texto (qué información va primero, segundo, tercero).
3. **Señalar estructuras clave:** "Mi padre se llama… y tiene… años." Marcar las que el alumno va a necesitar.
4. **Producción paralela (4 min):** El alumno escribe sobre sí mismo siguiendo la misma estructura. Modelo visible (apoyo total).
5. **Corrección entre pares (2 min):** Textlupe simplificada — cada alumno verifica UN aspecto del texto del compañero.
6. **Diferenciación:** Basis = con modelo; Extra = con modelo + 1 frase extra; Plus = sin modelo.

**Principio teórico:** Lectura + producción como modelo (§3.4 repertorio destrezas) + weaning off por diferenciación.

#### Opción B — Lectura + extracción + producción enriquecida

**Cuándo:** Texto modelo rico en vocabulario nuevo, necesidad de extraer y reutilizar vocabulario antes de producir.

**Secuencia:**
1. **Lectura global (2 min).**
2. **Extracción de vocabulario (2 min):** "Subrayad todas las palabras de familia/parentesco del texto." Listar en cuaderno.
3. **Clasificar vocabulario extraído (1 min):** Nuevo vs. ya conocido.
4. **Producción enriquecida (5 min):** Escribir texto propio usando AL MENOS 5 palabras de la lista.
5. **Lectura cruzada (2 min):** Intercambiar textos. "¿Tu compañero usó las 5 palabras?"

**Principio teórico:** Text mining aplicado a vocabulario + producción con requisito léxico mínimo.

### §2.6 Lee y escucha (vocabulario)

**Contexto:** Actividades donde el alumno lee un texto y lo escucha simultáneamente. Típicamente textos sobre personas/familias reales con foto.

#### Opción A — Pre-Durante-Post con foco en vocabulario

**Cuándo:** Texto informativo sobre persona/familia, vocabulario parcialmente nuevo, primera lectura/escucha de la unidad sobre el tema.

**Secuencia:**
1. **Pre-lectura (2 min):** Señalar foto. "¿Cómo se llama? ¿De dónde creéis que es?" Pre-enseñar 2-3 palabras clave que no son deducibles.
2. **Durante — Lectura silenciosa primero:** Comprensión global. "¿Cuántas personas hay en la familia de [nombre]?"
3. **Durante — Audio con texto visible:** Los alumnos escuchan mientras siguen el texto. (En A1.1, texto como apoyo a escucha REDUCE carga, §5.7.)
4. **Post-lectura — Extracción léxica (2 min):** "¿Qué palabras nuevas habéis encontrado?" Listar en pizarra.

**Principio teórico:** Pre-Durante-Post estándar (curso-general) + CLT §5.7 texto como apoyo en A1.

#### Opción B — Lectura contrastiva

**Cuándo:** Dos textos sobre personas/familias diferentes en la misma sección, vocabulario compartido entre ambos textos, posibilidad de comparación.

**Secuencia:**
1. **Leer texto 1 + audio.**
2. **Extraer vocabulario clave de texto 1.**
3. **Leer texto 2 + audio.**
4. **Comparar:** "¿Qué vocabulario se repite? ¿Qué es diferente?"
5. **Tabla comparativa:** Construir en parejas una tabla con vocabulario compartido y diferente.

**Principio teórico:** Reciclaje inmediato dentro de la misma sección + análisis contrastivo léxico.

### §2.7 Comprensión lectora (vocabulario)

**Contexto:** Preguntas de comprensión sobre textos leídos, con foco en verificar comprensión del vocabulario en contexto.

#### Opción A — Preguntas escalonadas

**Cuándo:** Texto con información específica, preguntas de localización (dónde, quién, cuántos), necesidad de verificar comprensión detallada.

**Secuencia:**
1. **Individualmente:** Responder las preguntas.
2. **Corrección en parejas:** Comparar respuestas. "¿Dónde en el texto está la respuesta?" (metacognición).
3. **Puesta en común:** Verificar con el grupo.

**Principio teórico:** Gagné: verificación de comprensión + metacognición (señalar evidencia en el texto).

#### Opción B — Búsqueda competitiva

**Cuándo:** Preguntas factuales claras, posibilidad de gamificar, clase con energía baja que necesita activación.

**Secuencia:**
1. **En parejas:** Buscar las respuestas lo más rápido posible.
2. **Primera pareja correcta levanta la mano.** Verificar: deben señalar DÓNDE en el texto.
3. **Punto extra de insignia** para la pareja ganadora.

**Principio teórico:** Gamificación integrada + metacognición (localizar evidencia).

---

### §2.8 Completa huecos (vocabulario)

**Contexto:** Actividades donde el alumno completa frases con el término de vocabulario correcto.

#### Opción A — Weaning off progresivo

**Cuándo:** Vocabulario recién presentado, necesidad de consolidar reconocimiento antes de producción libre.

**Secuencia:**
1. **Con banco de palabras visible:** Completar los huecos.
2. **Sin banco pero con inicial:** Completar con solo la primera letra visible.
3. **Sin apoyo:** Completar de memoria.
4. **Verificar:** Corrección en parejas.

**Principio teórico:** Weaning off 4 niveles (§8.11) — apoyo máximo → reducido → mínimo → sin apoyo.

#### Opción B — Interleaving

**Cuándo:** Vocabulario que conecta con unidades anteriores, posibilidad de mezclar nuevo + conocido.

**Secuencia:**
1. **Completar huecos del libro.**
2. **El profesor dicta 2-3 frases extra** que reciclan contenido anterior (nacionalidades, números, colores…) mezclado con vocabulario nuevo.
3. **Reflexión:** "¿Qué palabras son nuevas? ¿Cuáles ya conocíais?"

**Principio teórico:** Reciclaje dinámico (§6) — interleaving de contenido previo + metacognición.

#### Opción C — Huecos → producción libre

**Cuándo:** Huecos como trampolín hacia producción personal, vocabulario suficientemente dominado para producir.

**Secuencia:**
1. **Completar huecos del libro.**
2. **Producir frase propia:** "Ahora escribid una frase igual pero sobre VUESTRA familia/vida."
3. **Compartir en parejas.**

**Principio teórico:** Transición de receptivo a productivo — la producción cierra el ciclo (§8 F2b).

## 3. CRITERIOS DE SELECCIÓN

### Tabla de decisión

| Variable contextual | Valor | Opciones favorecidas |
|---------------------|-------|---------------------|
| **Posición en la unidad** | Primera aparición del campo semántico | §2.1A (input visual saturado), §2.5A (modelo → producción) |
| | Reciclaje / segunda aparición | §2.1B (categorización), §2.8B (interleaving) |
| **Cantidad de ítems nuevos** | ≤5 | Cualquier opción sin segmentar |
| | 6-10 | §2.1B (categorización en subcategorías) |
| | >10 | §2.1B obligatorio + §2.2B (escucha segmentada) |
| **Recursos disponibles** | Audio + imagen rica | §2.1A (input visual saturado) |
| | Solo audio | §2.2A o §2.2B |
| | Solo texto | §2.5A o §2.5B |
| **Patrón regular** | Sí (género -o/-a, plural -s/-es) | §2.1A con awareness |
| | No / excepciones | §2.1A sin awareness (deductivo: mostrar excepción directamente) |
| **Contenido reciclable** | Alto (muchas conexiones con U anteriores) | §2.8B (interleaving), §2.4C (encuesta) |
| | Bajo | §2.8A (weaning off), §2.4A (diálogo modelo) |
| **Conexión personal posible** | Sí (familia, gustos) | §2.4C (encuesta), §2.5A (producción paralela), §2.8C (huecos → producción) |
| | No (vocabulario técnico) | §2.4B (gap información), §2.5B (extracción) |
| **Energía del grupo** | Baja | §2.7B (competitiva), §2.4C (encuesta con movimiento) |
| | Alta | §2.4A (diálogo), §2.7A (preguntas escalonadas) |
| **Actividad adyacente** | Gramática viene después | Explotar exposición incidental al patrón gramatical (señalar sin formalizar) |
| | Producción viene después | §2.5A (modelo → producción) como preparación |
